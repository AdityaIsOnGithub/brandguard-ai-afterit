## 🚀 Overview
**BrandGuard AI** is an explainable, human-in-the-loop brand-governance platform powered by **Brand Vector DNA**. It reviews high-velocity marketing content before publication, checking it against approved brand guidelines, factual claims, tone vectors, visual hex palettes, and WCAG accessibility standards[cite: 10]. 

Instead of acting as a black-box filter that rejects or overwrites a creator's work, BrandGuard AI pinpoints exact violations, provides plain-English explanations, and offers non-destructive **1-Click Smart Fixes** while maintaining a full audit trail[cite: 10].

---

## ✨ Key Features Built (Round 2 MVP)

1. **Multi-Brand Vector DNA Knowledge Base:** Dynamic state engine supporting distinct brand profiles (*NovaPay FinTech*, *VerveBio Health*, and *AuraCloud AI*) complete with approved facts, forbidden terms, and hex palettes[cite: 10].
2. **1-Click Judge Quick-Test Scenarios:** Pre-loaded test cases allowing evaluators to instantly test high-violation posts, medical claim drifts, and compliant releases without setup friction[cite: 10].
3. **Real-Time Text & Factual Claim Scanner:** Inline contextual highlighting that flags unsupported promotional claims and guideline drift with exact rule ID citations (e.g., `FIN-CLAIM-01`, `WCAG-AA-01`)[cite: 10].
4. **Non-Destructive 1-Click Smart Fix Engine:** Automatically replaces problematic phrases while preserving creator intent, backed by a live **Human-in-the-Loop Revision Audit Trail**[cite: 10].
5. **Visual Palette & WCAG 2.1 AA Contrast Inspector:** Client-side HTML5 Canvas pixel sampling for dominant hex extraction and real-time contrast ratio calculation[cite: 10].
6. **Role-Based Collaboration Queue:** Seamless persona switching between **Content Creator** (who drafts and submits) and **Brand Manager** (who reviews, comments, approves, or requests revisions)[cite: 10].
7. **Governance Insights Dashboard:** Analytics tracking recurring team mistakes and review cycle reductions[cite: 10].

## 🛠️ Technology Stack & Architecture

* **Frontend & Workspace:** React 18, Tailwind CSS, Lucide Icons (engineered as a responsive, zero-latency single-page application)[cite: 10].
* **Hybrid Governance Architecture:**
  * **LLM & Multimodal Layer:** Integrates with Google **Gemini 3 Flash** structured JSON outputs (`responseSchema`) for nuanced tone evaluation and visual asset scanning[cite: 10].
  * **Deterministic Reliability Layer:** A synchronous regex, fact-verification, and WCAG contrast engine running in parallel to guarantee 100% uptime, sub-50ms feedback, and zero hallucinated rule citations during evaluation[cite: 10].
